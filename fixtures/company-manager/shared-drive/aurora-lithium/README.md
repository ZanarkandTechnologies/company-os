# Aurora Lithium — project document register

`sources/` contains the current records available for this planning cycle.
`examples/` contains format references only and is not a project evidence
source. `published/` is reserved for reviewed work approved for circulation.

```text
sources/finance/       cash, budget, and model assumptions
sources/growth/        investor audience and market material
sources/operations/    compliance, contractor, and risk records
sources/mining/        geo, exploration, and production records
sources/management/    priorities and operating cadence
examples/              format references only
published/             reviewed work approved for circulation
```
