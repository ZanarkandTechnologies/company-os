# Aurora Lithium technical source — 17 August 2026

Aurora Lithium is located in the Pilbara, Western Australia. The current
dataset contains 64 completed drill holes and a modelled 12.8 million tonnes at
1.42% average lithium grade. It does not include a resource classification or
economic study conclusion. The Technical Lead must review any interpretation
before the data is used in a fundraising document.

Data limitation: no current metallurgy, recovery, mine design, permitting, or
code-compliant resource statement is included in the current project record.
