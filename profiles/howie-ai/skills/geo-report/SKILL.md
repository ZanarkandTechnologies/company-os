# Geo report

Use this skill only after reading the required source from the approved shared
shared Drive source. Write one draft to the owning ticket's `artifacts/` directory.
Do not manufacture geological facts. Copy a fact only when the approved source
states it. The source path, source date, and every numerical claim must be
visible in the draft. State limitations and request technical review in the
draft.

## Evidence discipline

- Do not infer a deposit type, mineralogy, resource confidence category,
  technical code classification, recovery, economic viability, or drill density
  conclusion unless the approved source explicitly states it.
- In **Geological interpretation**, write only source-backed observations. If
  the source supplies numbers but no interpretation, say exactly that and name
  the missing evidence.
- The draft is not a JORC, NI 43-101, or other technical disclosure. Never use
  language that implies one.
- Cite the approved source path in **Project and source** and **Data
  limitations**. Preserve the reviewer request; review approval, not drafting,
  is the gate for downstream work.

Use [the report template](templates/geo-report.md) as the required outline.
