# Production performance report

Use for a defined production period. Require verified operating data, target or
plan basis, source date, accountable operating owner, and reviewer. Use
[the template](templates/production-performance-report.md). Separate source
observations from hypotheses; do not state safety, production, quality, or cost
conclusions that the supplied evidence does not support.

Missing production data or owner explanation must block the artifact or create
an explicit ticket requirement.
