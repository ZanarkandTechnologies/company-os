# Exploration program

Use only with an approved technical source set, program objective, site/safety
constraints, budget assumption, and named technical reviewer. Populate
[the template](templates/exploration-program.md) with evidence citations and
explicit data limitations. Do not infer resource classification, drilling
results, approvals, or safe operating conditions.

The output is a program draft, not an authorisation to mobilise contractors or
conduct field work.
