# Weekly operating report

Use after its named upstream work has been approved. It is a management
decision document: completed work, live blockers, owner decisions, dates,
risks, and next-week priorities. Save the draft only under the owning ticket's
`artifacts/` directory and use
[the template](templates/weekly-operating-report.md). Cite ticket and artifact
references rather than copying uncited claims.

Record `work_started` and `artifact_drafted`, name an executive reviewer, and
never represent an unresolved upstream artifact as complete.
