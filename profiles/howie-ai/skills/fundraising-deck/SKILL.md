# Fundraising deck

Use only after an approved technical source/output, approved financial case,
audience direction, and named reviewer are present. Write a draft only to the
owning ticket's `artifacts/` directory and request review. Use
[the deck template](templates/fundraising-deck.md). Cite source outputs and
label every assumption; do not invent valuation, resource classification,
commitments, or funding availability.

Record `work_started` and `artifact_drafted` in progress, then set the ticket
to `awaiting_review`. An unresolved technical, finance, or audience input is a
requirement on the ticket, never a gap hidden in the deck.
