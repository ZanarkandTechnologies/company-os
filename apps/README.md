# Applications

User-facing and runtime applications live here with their schemas and tests.

- `company_os/`: Daily/Weekly automation harness and delivery runtime.
- `doctor/`: read-only operator diagnostics and feature readiness.
- `installer/`: setup, provider configuration, certification, and maintenance.
- `eval_viewer/`: private static evidence viewer.

Provider-specific adapters remain in `plugins/`; automation instructions remain
in `automations/`.
